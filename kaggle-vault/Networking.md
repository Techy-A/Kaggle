## What works
- **1–2 comments a day, each with data, code or a precise answer.** Never "great work!".
- Reply to threads with **0 replies** that ask for input (Bull's "Validation strategy").
- Keep the other person's tone: casual threads get casual replies.
- Put links at the end, after the value. **Make the linked notebook public before posting.**
- Never post personal contact details in public. Teaming happens through Kaggle usernames (Team tab → merge).
- Upvote and thank the notebooks you build on.
- Logged-out views (and my API checks) may not show new comments. Use the **bell icon**.
